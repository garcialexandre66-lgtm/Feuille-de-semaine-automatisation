Validation disponible à partir du vendredi. Pour une semaine incomplète ou avec une absence, vérifiez le crédit avec l’entreprise. Une correction des heures demande une nouvelle validation. Une semaine d’école confirmée crédite le compteur sans inventer ses horaires journaliers.

    Prévoir une absence

    Choisissez un jour ou une période, même plusieurs semaines à l’avance.

    Congés : le samedi compte, le dimanche est exclu. Si la période se termine un vendredi, le samedi suivant est inclus.

    Le motif choisi sera inscrit sur chaque journée sélectionnée dans le PDF. Aucune heure travaillée ou supplémentaire ne sera ajoutée. Maximum : 366 jours par période.
