Feuille de semaine

Vos journées, votre feuille de semaine.

Feuille de semaine est un carnet d’interventions professionnel. Il permet de renseigner les chantiers, les clients, les déplacements, le temps passé à l’atelier et les journées de cours ou d’absence, puis de préparer une feuille récapitulative.

Du suivi quotidien à l’envoi du PDF

  • Enregistrer et organiser les interventions de chaque journée.
  • Consulter les heures, le calendrier et les tâches.
  • Générer une feuille de semaine en PDF ou au format tableur.
  • Vérifier le PDF et le message avant de confirmer l’envoi à la destinataire prévue.

Un espace personnel

Les feuilles sont accessibles après connexion avec le code de l’espace. Une copie locale chiffrée permet de préparer le travail hors connexion sur un appareil déjà configuré.

Connexion Google facultative

La connexion à Google sert à envoyer les feuilles via Gmail. L’option d’envoi programmé peut également classer les PDF dans les fichiers Drive créés par l’application. Les autorisations demandées et l’utilisation des données sont décrites dans la politique de confidentialité.

La configuration Google doit être terminée par le gestionnaire de l’application avant de pouvoir connecter un compte. La disponibilité de ces fonctionnalités dépend des autorisations Google accordées.

Ouvrir mon espace

Projet et assistance technique : Feuille de semaine sur GitHub. Pour les données de votre espace, utilisez le contact d’assistance présenté lors de l’autorisation Google ou contactez directement le gestionnaire qui vous en a donné l’accès.
